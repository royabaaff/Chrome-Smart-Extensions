\# 🚀 Chrome Smart Extensions Suite



A collection of lightweight, high-performance, and dark-themed Google Chrome extensions built with \*\*Vanilla JavaScript\*\* and \*\*Manifest V3\*\*. These tools are engineered to optimize browser performance, manage networks, and improve UI without relying on heavy external libraries.



\## 📦 The Suite Includes:



\### 1. 🌍 Smart SOCKS Proxy

A minimalistic proxy manager with live IP/Geo-location tracking.

\- \*\*Zero Background RAM Usage:\*\* Runs checks only when opened.

\- \*\*Smart Bypass:\*\* Pre-configured bypass list for national domains.

\- \*\*Visual Status:\*\* Live badge indicators.



\### 2. 🚀 Smart RAM Saver

An automated memory optimizer that discards idle tabs.

\- \*\*Smart Timeout:\*\* User-defined timeout using Chrome's `lastAccessed` API.

\- \*\*Panic Button:\*\* Instantly discard all inactive tabs with one click.

\- \*\*Visual Toggle:\*\* ON/OFF badge indicator on the extension icon.



\### 3. ✨ Smart RTL Fixer

Intelligent right-to-left (RTL) text formatter for Persian/Arabic content.

\- \*\*Auto-Domain Memory:\*\* Automatically triggers on user-saved domains (e.g., ChatGPT, Gemini).

\- \*\*Code Protection:\*\* Isolates English code blocks and UI elements to prevent layout breaks.

\- \*\*Vazirmatn Typography:\*\* Forces clean, readable fonts.



\### 4. 🔖 Smart Bookmark Manager

A cloud-synced bookmarking interface leveraging Chrome's native sync.

\- \*\*No Database Needed:\*\* 100% synced with your Google Account.

\- \*\*Smart Detection:\*\* Real-time green checkmark (✔) on the icon if the current tab is bookmarked.

\- \*\*Custom Folders:\*\* Create and manage categories directly from the popup.



\## 🛠️ Technology Stack

\- \*\*Core:\*\* JavaScript (ES6+), HTML5, CSS3

\- \*\*Architecture:\*\* Chrome Extension Manifest V3, Service Workers

\- \*\*Design System:\*\* Unified Dark Theme (`#1a1a24` background, `#4da3ff` primary accents), Vanilla CSS variables.



\## 📥 Installation (Developer Mode)

1\. Clone this repository: `git clone https://github.com/royabaaff/Chrome-Smart-Extensions.git`

2\. Open Chrome and navigate to `chrome://extensions/`

3\. Enable \*\*Developer mode\*\* (top right corner).

4\. Click \*\*Load unpacked\*\* and select the folder of the specific extension you want to use.
