\# Chrome Smart Extensions



A curated collection of high-performance, lightweight Chrome extensions built on Manifest V3, designed to enhance web productivity, system optimization, proxy management, and text styling.



\## Included Extensions



\### 1. Smart Bookmark Manager

An advanced utility designed to streamline bookmark organization, categorization, and quick search access within Google Chrome.



\### 2. Smart RAM Saver

A performance optimization extension that automatically manages browser memory usage and unloads inactive tabs to conserve system resources.



\### 3. Smart RTL Fixer

An intelligent right-to-left (RTL) text alignment and typography extension tailored for chat interfaces and web applications, featuring dynamic font scaling and Persian typography support.



\### 4. Smart SOCKS Proxy

A secure and efficient proxy management extension enabling fast routing configuration directly within the browser.



\## General Installation \& Setup



1\. Clone or download this repository to your local machine.

2\. Open Google Chrome and navigate to `chrome://extensions/`.

3\. Enable \*\*Developer mode\*\* using the toggle switch in the top-right corner.

4\. Click \*\*Load unpacked\*\* and select the folder of the specific extension you wish to install.
